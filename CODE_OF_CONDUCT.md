# Code of Conduct

k8sgpt is a [Cloud Native Computing Foundation](https://www.cncf.io) project and follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

To report a concern, email the maintainers at contact@k8sgpt.ai. If the concern involves a maintainer, or you are not comfortable reporting to the project, contact the [CNCF Code of Conduct Committee](https://www.cncf.io/conduct/committee/) at conduct@cncf.io.
